# Генератор технического задания (ТЗ) — CaseBridge

Веб-приложение на Flask для быстрого создания структурированных технических заданий.  
Пользователь заполняет форму — и получает готовый документ в одном из четырёх форматов: **MD**, **TXT**, **PDF** или **ZIP** (все форматы + прикреплённые файлы).  
Также можно скопировать текст ТЗ в буфер обмена.

Интерфейс в тёмном стиле CaseBridge, ориентирован на людей без технического бэкграунда: большинство полей необязательны, сложные технические вопросы скрыты под спойлером.

---

## 🔥 Возможности

- 📝 **Генерация ТЗ** на основе заполненной веб-формы.
- 🎨 **Тёмный адаптивный интерфейс** в стиле CaseBridge.
- 📂 **Форматы выгрузки**: Markdown, Plain Text, PDF, ZIP‑архив.
- 📋 **Копирование текста** прямо из браузера (TXT).
- 🔒 **Плашка «СЕКРЕТНО»** — если проект под NDA, предупреждение показывается на странице и в документе.
- 📎 **Загрузка файлов** — скриншоты, макеты, референсы. Они попадают в ZIP‑архив и упоминаются в ТЗ.
- 🧩 **Гибкая форма**:
  - Тип проекта (скрипт, сайт, автоматизация, другое).
  - Уровень проработки (готовое решение, детальный проект, шаблон).
  - Бюджет (в любой валюте или даже «пачках сухариков»).
  - Контактные данные (обращение, email, телефон, Telegram, удобный способ связи).
  - Уточняющие вопросы (сроки, примеры, критерии готовности, ограничения и др.).
  - Расширенные технические настройки (язык, архитектура, БД, тестирование, документация, поддержка).
  - Свои параметры (key-value, добавляются динамически).
- 🖨️ **Красивый PDF** с цветными заголовками (цвет подхватывается из палитры сайта).
- 📦 **Всё в одном файле** — минимальные зависимости, запуск одной командой.

## ⚙️ Требования

- **Python 3.8+**
- Установленные пакеты: `flask`, `reportlab`
- **Windows**: системный шрифт Arial (`C:\Windows\Fonts\arial.ttf`) используется автоматически.  
- **Linux/macOS**: необходимо положить любой TrueType‑шрифт с кириллицей (например, `DejaVuSans.ttf`) в папку со скриптом, или скрипт попытается использовать первый найденный `.ttf` в текущей директории.

---

## 🚀 Установка и запуск

1. **Клонируйте репозиторий или сохраните файл `app.py`** (содержит весь код).
2. **Установите зависимости**:
   ```bash
   pip install flask reportlab
   ```
3. **Запустите приложение**:
   ```bash
   python app.py
   ```
4. Откройте в браузере:  
   **http://127.0.0.1:5000**

Страница с формой откроется автоматически. Заполните нужные поля и скачайте ТЗ в нужном формате.

---

## 📖 Использование

1. Введите **название проекта** (обязательно).
2. Выберите **тип проекта** и заполните соответствующие поля.
3. Укажите **уровень проработки**, бюджет, аудиторию, при необходимости загрузите файлы.
4. Просмотрите **уточняющие вопросы** — они помогут сделать ТЗ точнее, но заполнять их не обязательно.
5. При желании раскройте **«Сложные настройки»** и укажите технические детали.
6. Добавьте **свои параметры** через кнопку «+ Добавить».
7. Заполните **контакты** (необязательно, но удобно).
8. Нажмите одну из кнопок:
   - **Скачать MD / TXT / PDF** — отдельные документы.
   - **Скачать ZIP** — архив со всеми форматами и прикреплёнными файлами.
   - **Копировать TXT** — скопировать текст ТЗ в буфер обмена (требуется разрешение браузера).

Если выбран режим **«Нельзя (секретно)»** в вопросе о конфиденциальности, сверху формы появится красная плашка «СЕКРЕТНО», а в документе добавится соответствующая пометка.

## 💡 Примечания

- **PDF и шрифты**: на Windows приложение автоматически использует `C:\Windows\Fonts\arial.ttf`. Если файл отсутствует, положите любой TTF‑шрифт с русскими буквами в папку со скриптом (например, `DejaVuSans.ttf`).
- **Копирование в буфер**: функция «Копировать TXT» требует, чтобы сайт был открыт по HTTPS или `localhost` (для `navigator.clipboard`). В режиме разработки на `127.0.0.1` работает.
- **ZIP‑архив**: включает все сгенерированные документы + оригиналы загруженных файлов.
- **Безопасность**: загружаемые файлы сохраняются во временной папке, удаляемой при завершении работы ОС. Не используйте в публичном доступе без дополнительной настройки.
